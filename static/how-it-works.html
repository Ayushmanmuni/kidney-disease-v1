System Architecture

How It Works

A detailed look at the predictive pipeline — from patient data collection to real-time kidney disease risk prediction using machine learning.

📋 System Overview

Our CKD Prediction System uses a trained Random Forest Classifier to analyze clinical biomarker data and predict the probability of Chronic Kidney Disease. The system is designed for both clinical and educational use and offers two distinct input modes:

🏥

Patient Mode

A simplified 8-question form designed for individuals concerned about their kidney health. Uses medically-informed defaults for the remaining 16 parameters. Provides an easy-to-understand risk explanation.

👨‍⚕️

Doctor Mode

Full clinical interface with all 24 biomarker inputs organized in a 4-step wizard. Provides detailed health score, biomarker health grid, and feature importance chart for in-depth analysis.

Step by Step

The Prediction Pipeline

1

Data Input

The user enters clinical biomarker values via the web form. In Patient Mode, 8 key parameters are collected; the remaining 16 are filled with population-average defaults. In Doctor Mode, all 24 parameters are entered directly.

Parameters include: Age, Blood Pressure, Specific Gravity, Albumin, Sugar, Blood Glucose, Blood Urea, Serum Creatinine, Sodium, Potassium, Hemoglobin, Packed Cell Volume, WBC Count, RBC Count, and 10 categorical markers.
2

Data Preprocessing

The backend receives the 24-parameter JSON payload. Categorical values (e.g., "normal", "abnormal", "present", "not present") are encoded into numerical representations using a predefined encoding map that matches the training data format.

Encoding examples: "normal" → 1, "abnormal" → 0, "present" → 1, "notpresent" → 0, "yes" → 1, "no" → 0
3

Feature Vector Construction

The 24 encoded values are assembled into a feature vector in the exact order expected by the trained model. This ordering matches the column order from the original UCI CKD dataset used during training.

Feature order (24 features): age, bp, sg, al, su, rbc, pc, pcc, ba, bgr, bu, sc, sod, pot, hemo, pcv, wc, rc, htn, dm, cad, appet, pe, ane
4

Random Forest Prediction

The feature vector is passed to the pre-trained Random Forest Classifier. The model consists of 200 decision trees, each trained on a different bootstrap sample of the training data. Each tree "votes" independently and the final prediction is based on the majority vote.

Output: Binary classification (CKD / Not CKD) + probability score from 0% to 100% based on the proportion of trees voting for each class.
5

Result Visualization

The prediction, probability, and input data are sent back to the frontend, where results are displayed using interactive visualizations tailored to the mode:

  • Risk gauge — semicircular meter showing probability (green → yellow → orange → red)
  • Health score ring — circular score visualization (100 minus risk percentage)
  • Health grid — per-biomarker assessment with normal/warning/critical status (Doctor mode)
  • Feature importance chart — horizontal bar chart of which biomarkers most influenced the prediction (Doctor mode)
  • Patient explanation — plain-language summary of the risk level and recommended next steps (Patient mode)

Python + Flask
Backend

Lightweight Python web framework serving the API and static files. Handles prediction requests and data preprocessing.

scikit-learn
Machine Learning

Industry-standard ML library. RandomForestClassifier with 200 estimators, trained on UCI CKD dataset with 5-fold cross-validation.

Vanilla JS
Frontend

No frameworks — pure HTML5, CSS3, and JavaScript for maximum compatibility and zero dependencies. Canvas API for charts.

joblib
Model Serialization

Efficient Python object persistence. The trained model is serialized to disk and loaded on server startup for instant predictions.

🤖 Model Training Methodology

The training pipeline follows a rigorous process to ensure maximum accuracy and generalizability:

1. Data Cleaning & Imputation

The raw dataset contains approximately 20% missing values. A combined imputation strategy is used: KNN Imputer for numerical features (considering the 5 nearest neighbors) and mode imputation for categorical features. Records with more than 50% missing values are excluded.

2. Feature Encoding

Categorical features are label-encoded into binary (0/1) or ordinal values. Features like Red Blood Cells ("normal"→1, "abnormal"→0), Pus Cell Clumps ("present"→1, "notpresent"→0), and Hypertension ("yes"→1, "no"→0) are converted to numerical form.

3. Dataset Splitting

The cleaned dataset is split 80/20 into training and test sets using stratified sampling to maintain the CKD/not-CKD ratio in both partitions.

4. Multi-Model Comparison

Five different algorithms are trained and compared:

Model Accuracy Key Strengths
Random Forest~99%Best overall accuracy, robust to outliers, handles mixed feature types
Gradient Boosting~98%Strong sequential learning, excellent on tabular data
SVM (RBF Kernel)~97%Effective in high-dimensional spaces, good margin separation
Logistic Regression~96%Fast, interpretable, good baseline for binary classification
K-Nearest Neighbors~95%Simple, instance-based, effective with normalized features

5. Cross-Validation

5-fold stratified cross-validation is used to assess model stability. The Random Forest model achieves consistent accuracy across all folds, confirming it is not overfitting to any specific data partition.

6. Model Selection & Serialization

The Random Forest Classifier is selected as the production model based on the highest cross-validated accuracy. It is serialized to disk using joblib as best_ckd_model.pkl and loaded by the Flask server on startup.

📈 Top Predictive Features

Features ranked by their importance in the Random Forest model

1

Hemoglobin (hemo)

The most important predictor. Low hemoglobin levels strongly correlate with CKD due to reduced erythropoietin production by damaged kidneys.

2

Specific Gravity (sg)

Measures urine concentration. Damaged kidneys lose the ability to concentrate urine, resulting in lower specific gravity values.

3

Albumin (al)

Protein in urine (albuminuria) is an early marker of kidney damage. Higher albumin levels in urine indicate glomerular dysfunction.

4

Packed Cell Volume (pcv)

Percentage of blood volume occupied by red blood cells. Lower PCV reflects anemia, a common CKD complication.

5

Serum Creatinine (sc)

A key kidney function marker. High serum creatinine indicates the kidneys are not filtering waste effectively.

⚖️ Limitations & Ethical Considerations

  • Dataset size: 400 records is relatively small. Performance may vary on broader, more diverse populations.
  • Geographic bias: Data was collected from a single hospital in India and may not generalize to all demographics.
  • Missing data: ~20% of original values were imputed, which introduces some uncertainty.
  • Not a clinical tool: This system is for educational and screening purposes only. It is NOT a substitute for professional medical diagnosis.
  • Binary classification: The model predicts CKD/Not-CKD but does not stage the disease (Stage 1–5).
  • Temporal limitation: The model does not account for changes over time — it analyzes a single snapshot of biomarkers.

Transparency

How This Model Makes Decisions

🧬 Data Features Used

The model uses 24 clinical features including blood pressure, serum creatinine, blood urea, hemoglobin, glucose, sodium, potassium, and categorical findings.

🗂️ Medical Dataset Foundation

The model is trained on the UCI CKD dataset and evaluated with supervised machine learning methodology.

⚖️ Model Limitations

Predictions depend on data quality and population match. Performance can vary in out-of-distribution scenarios.

🩺 Diagnostic Boundary

This output is a risk estimate, not a diagnosis. Always interpret results with clinical context and a qualified professional.

⚠️ Limitations

Known Limitations

📊

Small Dataset

Trained on only ~400 patient records from the UCI repository. A production model would require thousands of diverse samples for reliable generalization.

🏥

Not Clinically Validated

This model has not been validated through clinical trials. It is an academic proof-of-concept and should never replace a doctor’s diagnosis.

🌍

Population Bias

The training data may not represent all demographics, ethnic groups, or geographic regions.

🧩

Missing Modern Biomarkers

Does not include eGFR, BMI, or family history — key modern indicators.
